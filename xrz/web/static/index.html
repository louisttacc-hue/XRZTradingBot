Einstellungen

In 5 Schritten startklar

1. Lokale KI (Ollama)…
2. Telegram verbinden Bei @BotFather in Telegram /newbot senden, Token unter Einstellungen → API-Keys eintragen.
Dann deinem Bot schreiben: /start ……
3. Optional: Claude/OpenAI-Key für deutlich schlauere Antworten (Einstellungen → API-Keys).
4. Paper-Trading testen – oben „Paper-Trading starten“ oder in Telegram /paper. Mindestens einige Wochen beobachten.
5. Live-Trading (Echtgeld) – Börsen-API-Key ohne Auszahlungsrechte eintragen, unter Einstellungen „Live-Trading freischalten“, dann /live und mit Code bestätigen. Klein anfangen!

TradingView-Alerts (optional)

1. Unter Einstellungen Webhook aktivieren und eine TradingView-Passphrase setzen, Bot neu starten.
2. Den Webhook-Port ins Internet freigeben, z. B. mit Cloudflare Tunnel: cloudflared tunnel --url http://localhost:8766
3. In TradingView beim Alarm „Webhook-URL“ = https://DEINE-TUNNEL-ADRESSE/webhook/tradingview
4. Nachricht (JSON): {"passphrase":"DEINE_PASSPHRASE","symbol":"{{ticker}}","action":"buy"} (action: buy / sell / close)
Fertiges Pine-Script: tradingview/xrz_signale.pine im Projektordner.
